SageCureAbhi - AI-Powered Medical Consultation Chatbot
SageCureAbhi is a sophisticated, full-stack web application that simulates a preliminary medical consultation with an AI doctor. Powered by the high-speed Groq API and Google's Gemma model, this chatbot can understand user-described symptoms, ask clarifying questions, provide preliminary diagnoses, generate downloadable prescriptions, and even suggest local doctors.

The application is designed with a clean separation between its Python (FastAPI) backend and its React frontend. It features a robust, stateful chat interface where conversations are saved locally, allowing users to review, delete, or clear their session history.

✨ Features
AI Doctor Persona: The chatbot, "Dr. SageCureAbhi," uses a sophisticated prompt to act as an empathetic and professional AI doctor.

Symptom Analysis & Prescription Generation: The AI analyzes symptoms and generates a structured, downloadable prescription with a diagnosis, medications, and advice.

Downloadable PDF Prescriptions: Prescriptions generated in the chat can be instantly downloaded as a professionally formatted PDF.

Location-Based Doctor Recommendations: Includes a simulated database to recommend real-world doctors and specialists in Indore, India, based on user queries.

Complete Chat History Management:

View the entire conversation on a dedicated dashboard.

Delete individual messages from the history.

Clear the entire database to start a new session with a single click.

Critical Symptom Alerts: A rule-based "Red Flag" system immediately detects critical symptoms and advises the user to seek emergency medical help.

Intuitive User Interface: A clean, responsive UI built with React, featuring template prompts to guide the user's interaction.

🛠️ Tech Stack
Frontend: React.js (CSS-in-JS for styling, no external CSS frameworks)

Backend: Python 3.10+ with FastAPI

AI Engine: Groq API running the Gemma (gemma-7b-it) model

Database: SQLite (for simple, local, file-based data persistence)

PDF Generation: jspdf library on the frontend

🚀 Getting Started
Follow these steps to set up and run the project on your local machine.

Prerequisites
Node.js and npm: Required for the frontend. Download from nodejs.org.

Python 3.10 or higher: Required for the backend. Download from python.org.

1. Clone the Repository
First, clone this project to your local machine:

git clone <your-repository-url>
cd sagecureabhi-project

2. Backend Setup
You will need one terminal for the backend.

Navigate to the backend directory:

cd backend

Create and activate a Python virtual environment:

# For Windows
python -m venv .venv
.\.venv\Scripts\activate

# For macOS/Linux
python3 -m venv .venv
source .venv/bin/activate

Install the required Python packages:

pip install -r requirements.txt

Add your Groq API Key:

Get your free API key from the Groq Console.

Open the backend/main.py file.

Find the line GROQ_API_KEY = os.getenv("GROQ_API_KEY", "YOUR_GROQ_API_KEY_HERE") and replace "YOUR_GROQ_API_KEY_HERE" with your actual key.

Run the backend server:

uvicorn main:app --reload

Your FastAPI backend is now running at http://127.0.0.1:8000.

3. Frontend Setup
You will need a second, separate terminal for the frontend.

Navigate to the frontend directory:

cd frontend

Install the required Node.js packages:

npm install

Run the frontend development server:

npm start

This will automatically open a new tab in your browser. Your React application is now running at http://localhost:3000.
